Connexion pour Home Assistant

Cette étape se fait une seule fois sur un PC avec Python 3.12 ou plus. Ensuite, vous pourrez prendre les photos depuis votre téléphone.

  1. Téléchargez l'assistant et extrayez le fichier ZIP.
  2. Dans le dossier extrait, exécutez les deux commandes ci-dessous.
  3. Connectez-vous sur la page officielle OpenAI et autorisez l'utilisation du forfait.
  4. Importez le fichier connexion-stuffmanager.chatgpt créé par l'assistant.
python -m pip install -r requirements.txt
python connect_chatgpt.py

Sous Windows, utilisez py à la place de python si nécessaire. Le fichier de connexion est chiffré pour ce module et reste importable pendant une heure. Un nouveau téléchargement remplace la tentative précédente.

Pour ajouter un autre compte ou espace ChatGPT, lancez python connect_chatgpt.py --new-account.
